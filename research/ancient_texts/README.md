# Ancient Text Intelligence Program (ATIP)

Status: ACTIVE research expansion
Parent program issue: #429
Method parents: #377 #378 #381 #382 #387 #425

## Operating scope

ATIP applies the Layered Systems Reasoning Protocol to all **accessible, provenance-bearing ancient text corpora** rather than claiming literal possession of every surviving or lost ancient text.

A record is admissible only when its source, witness, rights/access status and uncertainty can be represented.

## Core evidence chain

raw witness
-> diplomatic transcription
-> normalized transcription
-> transliteration
-> segmentation
-> morphology/syntax
-> translation
-> interpretation
-> intertextual/cross-domain hypotheses
-> measurable tests
-> falsification
-> specialist review
-> claim state

Earlier layers are immutable evidence; later layers are annotations, not replacements.

## Four epistemic classes

1. KNOWN_DECIPHERED — positive-control texts.
2. PARTIALLY_CONSTRAINED — incomplete grammar, damaged witnesses, disputed readings.
3. UNDECIPHERED — structure analysis only; no running translation absent validated decipherment.
4. SYNTHETIC_NULL — shuffled/Markov/geometric/adversarial controls.

## Required analytical lenses

- witness/source criticism
- palaeography / glyph morphology
- layout/topology
- token/sequence statistics
- morphology/syntax
- semantic-role alignment
- translation variance
- scribal/provenance drift
- chronology/contact graph
- intertextual reuse
- numerical/calendrical/astronomical claims
- acoustic/phonological claims where historically warranted
- cross-domain correspondence
- adversarial falsification
- contamination/exposure accounting

## Non-conflation rules

visual resemblance != common origin
statistical regularity != language
language-likeness != decipherment
decipherment != translation
translation != interpretation
shared motif != organizational affiliation
shared frequency unit != physical coupling
modern reception != ancient provenance

## Program scale

Phase A: 1,000-record pilot.
Phase B: 10,000-record multi-corpus ingestion.
Phase C: corpus-specific full ingestion where authoritative access permits.
Phase D: cross-corpus graph, benchmark publication, specialist review.

The system must be capable of returning **UNRESOLVED** as a successful result.
