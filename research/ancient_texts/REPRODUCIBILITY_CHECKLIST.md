# ATIP v0.1 Public Reproducibility Checklist

A result is not publication-ready unless all applicable items are satisfied.

## Source integrity

- [ ] Exact repository / accession / stable identifier recorded.
- [ ] Witness version/date recorded.
- [ ] Source checksum recorded where technically possible.
- [ ] Rights state recorded independently for metadata, transcription, translation and media.
- [ ] Diplomatic transcription preserved separately from normalization.
- [ ] Damage, lacunae, uncertain signs and editorial restoration marked.

## Analysis integrity

- [ ] Epistemic class assigned.
- [ ] Contamination class assigned.
- [ ] Allowed evidence frozen before benchmark.
- [ ] Forbidden comparator recorded.
- [ ] Prediction frozen before reveal when benchmark is claimed as session-blind.
- [ ] Null models predeclared.
- [ ] Number of hypotheses tested reported.
- [ ] Multiple-comparison control applied where relevant.
- [ ] Negative results retained.

## Translation integrity

- [ ] Source-token / phrase alignment recorded.
- [ ] Supplied concepts marked.
- [ ] Competing lexical/morphological analyses retained.
- [ ] Witness differences retained.
- [ ] Restored material marked.
- [ ] Superseded readings linked.
- [ ] Translation difference class T0-T8 assigned.
- [ ] No single scalar "accuracy score" substitutes for the audit vector.

## Claim integrity

- [ ] Resemblance is not presented as transmission.
- [ ] Structure is not presented as decipherment.
- [ ] Decipherment is not presented as translation.
- [ ] Translation is not presented as historical intent.
- [ ] Numerical similarity is not presented as physical coupling.
- [ ] Extraordinary provenance is supported by primary/curatorial evidence.
- [ ] Novel readings receive specialist review before external promotion.

## Publication integrity

- [ ] Methods and code version identified.
- [ ] Data/witness access pathway documented.
- [ ] Reproducible commands or procedures supplied.
- [ ] Failures and unresolved cases included.
- [ ] Limitations section present.
- [ ] No claim exceeds its repository claim state.
