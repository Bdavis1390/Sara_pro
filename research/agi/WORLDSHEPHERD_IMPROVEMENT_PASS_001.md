# Worldshepherd Improvement Pass 001

## Scope

Apply the latest latent-state, identifiability, epistemic-action and OCOE work to existing Worldshepherd assets.

## SARA / admin-control plane

Existing project evidence already demonstrates:
- separate relay and admin tokens;
- admin-only audit and registry actions;
- smoke testing;
- a local integration test validating operator/admin separation and audit behavior.

Improvement:
- treat privileged endpoints as HIGH-CONSEQUENCE controllability;
- instrument every privileged action with observability coverage and rollback references;
- block self-generated governance changes from auto-promotion.

## Meta-alloy lane

The project itself currently labels major value unlock as dependent on filing, modeling, coupon validation and partner interest.

Improvement:
- preserve IP-stage claim ceiling;
- use active experimental design to select coupons/process settings with maximum information gain;
- bind every property claim to process parameters, specimen ID, test method and uncertainty through EBOM;
- update claim state only from physical evidence.

## Adaptive metasurface lane

The existing design already contains:
- sensing;
- state estimation;
- control computation;
- phase/material actuation;
- real-time feedback.

Improvement:
- attach observability confidence to each control state;
- define thermal/field safe envelope;
- if observability drops below threshold, reduce actuation authority or revert to passive safe state;
- log predicted vs observed field response to continuously calibrate the model.

## PRE / opportunity intelligence

Improvement:
- every forecast receives a timestamped probability and horizon;
- later opportunity outcomes score calibration;
- the system learns which indicators actually predicted demand;
- false positives/false negatives become training evidence;
- future scoring weights change only after held-out calibration.

## Translation

Improvement:
- use epistemic-action ranking to choose the next witness/parallel/source lookup;
- do not spend effort generating more prose when the uncertainty is witness-level;
- record unresolved equivalence classes explicitly.

## Consciousness

Improvement:
- rank proposed experiments by discriminating power between live theories;
- separate state observability from intervention controllability;
- require network/topology/state variables for frequency claims;
- preserve CMD-aware negative-evidence handling.

## Robotics/autonomy

Improvement:
- build a sensor-to-state observability matrix;
- build an actuator-to-state controllability matrix;
- highlight low-O/high-C dimensions;
- derate actuator authority in degraded sensing;
- retain human override and fail-safe modes.

## Cybersecurity

Improvement:
- preserve evidence before destructive remediation;
- use reversible containment when state remains ambiguous;
- treat audit/identity/process/network telemetry as one latent compromise-state estimator.

## Publication and claims

Improvement:
- every promoted result must carry EBOM, semantic snapshot and reproducibility manifest;
- failed or negative experiments remain first-class evidence;
- improvements that merely make prose more confident are not improvements.

## Recursive pass rule

After this pass, Worldshepherd uses the measured outcome of these changes to propose Pass 002.

No proposal is automatically a deployment.
