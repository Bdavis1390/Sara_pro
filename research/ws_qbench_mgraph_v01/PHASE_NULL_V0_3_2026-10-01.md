# WS-QBENCH-MGRAPH v0.3 — phase-topology null control

## Question

The v0.2 conductance control showed that raw random-subgraph `C_q` sits extremely close to a simple complete-bipartite sampling null. That makes conductance a weak candidate for an independent Worldshepherd feature unless it survives null correction.

The stronger question is therefore whether `lambda1` is driven merely by edge magnitudes/coarse hopping-order phase classes, or whether the **specific arrangement of the Laguerre-sign topology** contributes additional magnetic frustration.

## Delta-sign permutation null

`phase_null_v03.py` constructs a deliberately nonphysical adversarial null. For every hopping order `Delta = |n-m|`, it preserves:

- every edge magnitude at its original matrix location;
- the parity phase base `i**Delta`;
- symmetry of the hopping block;
- the exact multiset of positive/negative signs within that `Delta` band.

It randomizes only **where** those signs occur within the same hopping-order band.

This means the null keeps the magnitude structure and coarse `0, pi/2, pi, 3pi/2` phase classes while breaking the source graph's detailed sign topology.

## Independent numerical result

A separate NumPy/SciPy implementation was used as an independent cross-check with `Nmax=150`, 50 deterministic null permutations per eta, and seed `9675`.

`standardized separation` is `(source - null_mean)/null_std`. It is a descriptive permutation-ensemble distance, **not** a calibrated p-value and must not be reported as formal statistical significance.

## Interpretation

This control cuts both ways:

1. v0.2 showed that the raw conductance trend is almost completely explained by a simple sampling-geometry null;
2. v0.3 shows that the source graph's `lambda1` is consistently higher than phase-topology permutations that preserve magnitudes, hopping-order phase parity, symmetry, and per-band sign counts.

Within this bounded numerical model, that is evidence that the **arrangement of phase/sign topology contains information not reducible to edge magnitudes or the coarse parity phase class alone**. It is therefore a substantially stronger diagnostic for the source paper's phase-frustration mechanism than raw `C_q`.

This still does not prove a hardware mechanism, an experimental effect, or a causal interpretation outside the model. The null itself is intentionally nonphysical.

## Next gate

The next useful ablation should compare state localization (IPR or a Worldshepherd equivalent) under:

1. source topology;
2. delta-sign-permuted topology;
3. phase-stripped positive-weight topology;
4. magnitude-preserving fully randomized phases.

If localization tracks the same ordering as `lambda1`, that would strengthen the case that the source phase topology contributes incremental predictive information. If it does not, retain the negative result and downgrade the feature.
