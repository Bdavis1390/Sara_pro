# Identifiability Ceiling and Active Disambiguation

## 1. The deeper consequence of latent-state reasoning

Once a target is recognized as latent, a new question appears:

**Can the latent state be uniquely recovered from the observations we have?**

Sometimes the answer is no.

This is not merely a shortage of data.

If two models predict the same observable distribution under the available regime, adding more samples from that same regime can reduce sampling error without resolving which model is correct.

That is an **identifiability failure**.

## 2. Observational equivalence

Let hidden hypotheses H1 and H2 imply the same observational distribution:

P(Y | H1) = P(Y | H2).

Then observing more Y from the same distribution cannot, by itself, separate H1 from H2.

The correct output is not forced certainty.

It is an equivalence class:

{H1, H2}.

## 3. How interventions break equivalence

An intervention changes the data-generating process.

If:

P(Y | do(X=x), H1) != P(Y | do(X=x), H2),

then intervention X is discriminating.

The scientific objective becomes:

**choose the safest, cheapest observation or intervention expected to maximally reduce the remaining equivalence class.**

This is active inference in a broad methodological sense, not necessarily the specific Fristonian formalism.

## 4. Cross-domain impact

### Consciousness
A still body cannot uniquely identify internal conscious state.

### Medicine
Symptoms rarely uniquely identify etiology.

### Intelligence
Behavior rarely uniquely identifies intent.

### Science
Correlations can correspond to multiple causal graphs.

### Translation
A damaged inscription may support multiple reconstructions.

### Security
The same telemetry can be generated by benign and malicious processes.

### Finance
A bank deposit can have multiple economic meanings.

### Law/history
A summary can obscure multiple source/revision states.

### AI
Identical benchmark behavior can be produced by different internal algorithms.

## 5. The intervention ladder

Before acting, choose the lowest-risk discriminator:

1. retrieve richer source;
2. add another passive modality;
3. wait for temporal evolution;
4. use a natural experiment;
5. run a reversible perturbation;
6. perform a controlled intervention;
7. report equivalence class if safe discrimination is impossible.

## 6. Why this matters for AGI

A general agent should not merely answer:

"What is most likely?"

It should also know:

"Is the state identifiable from what I have?"

and:

"What observation/action would most efficiently distinguish the remaining possibilities?"

That introduces **epistemic action selection**.

The agent acts not only to change the world, but sometimes to learn which world it is in.

## 7. Connection to the original lesson

The original lesson rejected flattening an image into isolated symbols.

The latent-state lesson rejected flattening consciousness into observable behavior.

The identifiability lesson goes deeper:

**even all current observations together may still fail to uniquely specify the underlying reality.**

At that point intelligence requires designing a discriminating test.

This is the transition from passive pattern recognition to active scientific reasoning.
