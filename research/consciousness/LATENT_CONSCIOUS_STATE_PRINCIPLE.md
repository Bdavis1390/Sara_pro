# Latent Conscious-State Principle

## 1. Core result

The research path has crossed an important threshold.

Consciousness cannot safely be equated with:
- overt behavior;
- verbal report;
- one sensory channel;
- one neural frequency;
- one brain region;
- one measurement modality;
- one leading theory's preferred biomarker.

The most defensible systems representation is therefore:

**consciousness is a latent state inferred from converging, imperfect observables.**

This is not metaphysical evasion.
It is standard latent-variable reasoning applied to an unusually difficult biological construct.

## 2. Cognitive motor dissociation

In Bodien et al. (NEJM 2024), 353 adults with disorders of consciousness were assessed across six international centers.

Among 241 participants who showed no observable response to verbal commands:
- 60 (25%) demonstrated command-related cognitive activity on task-based fMRI, EEG, or both.

The tasks required sustained cognitive activity such as motor imagery.

Therefore:

behavioral nonresponse
does not imply
absence of task-responsive cognition.

This is directly relevant to the user's exclusion argument:

motor output is an interface.

It is not identical to consciousness.

## 3. 2026 meta-analytic strengthening

Laigaard et al. (European Journal of Neurology 2026) analyzed individual data from:
- 56 studies;
- 1,248 patients.

CMD detection varied with injury etiology and clinical state.

After multivariable adjustment:
- time since injury was not independently associated;
- task paradigm was not independently associated;
- diagnostic modality was not independently associated.

This matters because it weakens the idea that CMD is merely a peculiarity of one test technology.

It does not make any one CMD test infallible.

## 4. Leading theories remain incomplete

The Cogitate Consortium adversarial collaboration in Nature (2025) preregistered divergent predictions from IIT and GNWT and tested them using:
- fMRI;
- MEG;
- intracranial EEG;
- 256 human participants.

Neither theory received a clean victory.

IIT received support for some posterior content-maintenance predictions, but its predicted sustained posterior synchronization was not observed.

GNWT received some support for conscious-content representation, but the predicted prefrontal onset/offset ignition pattern was not found as specified.

The result is not:
"both theories are false."

It is:
**their tested biological implementations are incomplete or need revision.**

## 5. Measurement model

Let:

C(t) = latent conscious state

Observations:

B(t) = overt behavior
R(t) = verbal/manual report
E(t) = EEG features
F(t) = fMRI features
N(t) = network connectivity
P(t) = PCI/perturbational response
K(t) = criticality/complexity
Q(t) = non-equilibrium/FDT metrics
A(t) = autonomic/pupillary variables
S(t) = structural integrity

Then:

p(C | B,R,E,F,N,P,K,Q,A,S)

is the correct family of question.

Not:

C = B

or:

C = EEG_band_X.

## 6. Failure-mode-aware inference

Each observable needs its own failure model.

Behavior can fail because of:
- paralysis;
- motor pathway damage;
- fatigue;
- language impairment;
- fluctuating arousal.

EEG can fail because of:
- noise;
- poor montage;
- low sensitivity;
- analysis choice.

fMRI can fail because of:
- hemodynamic limitations;
- motion;
- scanner logistics;
- paradigm sensitivity.

Task-based paradigms can fail because of:
- impaired comprehension;
- working-memory limits;
- attention fluctuations.

Therefore a negative result means:

**no evidence detected under this measurement model**

unless stronger validation justifies more.

## 7. Theory-agnostic benchmark

Worldshepherd should separate:

### State detection
Can the system discriminate empirically validated conscious-state contrasts?

### Theory discrimination
Can it distinguish predictions unique to IIT, GNWT, recurrent processing, higher-order, criticality, or organized-energy models?

### Mechanism
Can causal perturbation change the predicted state variable?

### Generalization
Does the result hold across:
- species;
- anesthetics;
- injury etiologies;
- sensory modalities;
- laboratories;
- measurement technologies?

A biomarker should not be promoted into a theory merely because it classifies well.

## 8. AGI relevance

This result is directly relevant to general-agent research.

A system can produce fluent output without exposing:
- its true causal model;
- its uncertainty;
- its internal world-state representation;
- whether it can update after intervention;
- whether its symbols are grounded.

Therefore AGI evaluation should not equate:
benchmark output
with
internal general intelligence.

Instead test:
- hidden-state persistence;
- counterfactual reasoning;
- causal intervention;
- multimodal grounding;
- evidence revision;
- uncertainty;
- action-feedback learning.

The consciousness result teaches the same lesson as the original glyph analysis:

**observable surface behavior is not necessarily the underlying system state.**

## 9. Strongest current synthesis

The research path now supports this hierarchy:

energy supply
-> non-equilibrium neural dynamics
-> network organization
-> cross-frequency information transfer
-> latent conscious state
-> sensory/motor interfaces
-> report/action.

The arrows are hypotheses about organization, not proof of a final theory.

The key empirical constraint is that the final report/action layer can fail while deeper cognitive processing remains detectable.
