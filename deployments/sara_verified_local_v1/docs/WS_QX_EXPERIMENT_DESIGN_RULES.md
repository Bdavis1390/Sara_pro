# WS-QX Experiment Design Rules

1. Freeze the claim, baseline, metrics, thresholds, and mandatory dimensions before inspecting final results.
2. Prefer tests capable of falsifying the claim.
3. Retain negative and inconclusive outcomes.
4. Separate exploratory analysis from qualification runs.
5. Record configuration, environment, calibration, software/model versions, and deviations.
6. Quantify uncertainty where measurements support it.
7. Do not infer unmeasured physical properties from software or simulation.
8. Do not reuse a threshold from one domain/population/configuration without an explicit justification record.
9. Distinguish component evidence from system evidence.
10. Require independent replication/external evidence as a separate axis when the claim requires it.
