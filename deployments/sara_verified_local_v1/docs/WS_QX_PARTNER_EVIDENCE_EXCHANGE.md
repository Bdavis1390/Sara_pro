# WS-QX Partner Evidence Exchange Contract

Purpose: let a partner contribute bounded evidence without requiring proprietary source code or allowing marketing assertions to become qualification facts.

Minimum exchange record:

- partner evidence identifier
- originating organization
- releasability classification
- test date and environment
- hardware/configuration identity at a releasable level
- test protocol/version
- declared baseline
- measurement definitions and units
- result values and uncertainty/limitations
- raw-evidence availability or independent report reference
- chain-of-custody/integrity digest where available
- allowed-use statement
- claims explicitly supported
- claims explicitly not supported

Worldshepherd ingestion assigns an evidence class and provenance record. It does not automatically promote the partner's claim language. CANNOT DISCLOSE is treated as unavailable evidence for an external claim unless an authorized independent verifier can provide an acceptable attestation under the relevant qualification profile.

Partner evidence and Worldshepherd evidence remain distinguishable so a combined system claim can identify which component and organization actually supports each fact.
