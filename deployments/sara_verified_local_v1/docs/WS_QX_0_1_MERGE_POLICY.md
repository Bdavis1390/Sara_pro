# WS-QX 0.1 Merge Policy

Merge is authorized only through the repository's normal protected-main process after required checks succeed on the exact current PR head. Do not force-update main, disable protection, dismiss legitimate failures, or use historical checks as substitutes.

If branch protection reports a required context as expected/pending despite related workflow success, resolve the required context rather than bypassing it.

After merge, software publication state may advance to repository-published. Physical, external, standards, partner, and program qualification states do not advance merely because code merged.
