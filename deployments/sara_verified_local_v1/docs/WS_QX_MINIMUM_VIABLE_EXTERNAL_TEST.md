# WS-QX Minimum Viable External Test Package

An external test intended to advance E_R should receive a bounded package containing:

- claim under test and exclusions;
- qualification profile/version;
- immutable test inputs or input-selection protocol;
- declared baselines and metrics;
- acceptance criteria frozen before result disclosure;
- environment/equipment reporting requirements;
- deviations log;
- raw/derived evidence retention requirements;
- uncertainty/limitations reporting;
- result-signing or provenance method;
- conflict-of-interest and independence declaration appropriate to the test.

Worldshepherd should ingest the returned package as external evidence without rewriting failed or inconvenient outcomes. External testing does not automatically establish independent replication if the external party only reruns Worldshepherd's implementation; the replication ladder records that distinction.
