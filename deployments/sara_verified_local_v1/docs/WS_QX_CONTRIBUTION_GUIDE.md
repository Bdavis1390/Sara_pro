# Contributing to WS-QX

A new qualification profile should include:

1. bounded claim under test and exclusions;
2. declared baselines;
3. independent mandatory dimensions;
4. measurement definitions and units;
5. uncertainty/limitations model;
6. safety/abort controls where relevant;
7. raw and normalized evidence retention requirements;
8. deterministic or reproducible test fixtures where possible;
9. negative/adversarial tests;
10. explicit physical/external/program claim defaults;
11. Requirement Delta mapping;
12. claims matrix update.

Do not merge a profile merely because its documentation resembles a solicitation or standard. Tests should attempt to disprove promotion, not only demonstrate the happy path.
