# DV019 Evidence-Controlled Decision Gate

Before any Worldshepherd-supported Direct-to-Phase-II submission, verify the controlling solicitation and require program-specific evidence for every mandatory entrance criterion.

GO requires a qualifying prime/team to possess releasable Phase-I-equivalent evidence for the mandatory semantic-ISR entrance gates and a credible bounded integration plan.

CONDITIONAL GO is permitted only where the remaining work is documentation or bounded integration that does not require inventing missing prior evidence.

NO-GO / TRANSITION applies where mandatory prior evidence does not exist. In that case WS-SEMCAP/PRE retains the requirement as a capability-development target for future solicitations rather than converting planned work into historical evidence.

Worldshepherd software governance/evidence capability and a partner's physical/semantic performance evidence must remain separately attributable.
