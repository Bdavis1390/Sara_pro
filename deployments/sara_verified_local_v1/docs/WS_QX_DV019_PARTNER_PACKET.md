# WS-QX / DV019 Bounded Partner Evidence Packet

Use for non-proprietary partner screening. This packet is not a representation that Worldshepherd or a partner is DV019-qualified.

For each item answer PASS / PARTIAL / NO / CANNOT DISCLOSE and identify a releasable evidence reference if PASS/PARTIAL:

1. Prior EO-video prototype generating ROI or semantic transmissions rather than detection/tracking alone.
2. Mission/context/spatiotemporal reasoning dependent on persistence, behavior, relationships, or mission intent.
3. Semantic encoding/packetization implemented and demonstrated on representative hardware.
4. Experimentally measured transmitted-data reduction against a declared encoded full-video baseline, including metadata/communications overhead.
5. Measured embedded total-board power for the relevant configuration.
6. Measured sensor-to-semantic-packet latency for the relevant configuration.
7. Quantitative baseline comparison against appropriate codecs and/or conventional ROI/detection approaches.
8. Controlled degraded/intermittent/constrained-link test evidence and receiver resynchronization/reconstruction behavior.
9. Credible Group 1/2 UAS or representative platform integration evidence/path.
10. Decision-traceability metadata, model/configuration identity, SBOM/update/cyber artifacts.
11. Phase-I-equivalent evidence available for program-specific review.

Worldshepherd contribution can be evaluated separately for governed orchestration, authorization separation, controlled relay, evidence/provenance custody, configuration governance, degraded-state qualification, and validation instrumentation. No partner's evidence is silently attributed to Worldshepherd and no Worldshepherd software evidence is silently attributed to a partner's physical system.
