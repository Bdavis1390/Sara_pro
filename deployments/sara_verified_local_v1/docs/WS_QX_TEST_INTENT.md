# WS-QX Test Intent

Tests are designed to attack promotion boundaries, not merely exercise success paths.

Current test intent includes:
- dry/incomplete runs cannot qualify;
- one failed mandatory dimension blocks qualification;
- requested claim state cannot self-authorize promotion;
- internal qualification does not imply physical validation;
- external references cannot skip physical prerequisites;
- high data reduction cannot conceal low mission utility;
- critical-event misses remain failures despite bandwidth success;
- reconstruction and provenance fail independently;
- negative runs retain evidence digests;
- public/release manifests keep unsupported claims false.

Future tests should add replay, stale calibration, configuration substitution, evidence omission, timestamp manipulation, authorization failure, and external-attestation provenance attacks.
