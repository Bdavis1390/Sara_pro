# WS-QX Evidence Data Minimization

Qualification evidence should be sufficient for reproducibility and audit without indiscriminately collecting sensitive or unnecessary data.

Profiles should distinguish required raw evidence, derived evidence, metadata, and optional diagnostics. Partner/proprietary, personal, export-controlled, CUI, classified, or otherwise restricted information requires the appropriate handling environment and must not be placed in this repository merely to make an evidence record appear complete.

Where raw evidence cannot be shared, record the limitation and use an authorized external verification path when available. A digest of inaccessible data proves only integrity relative to the digest; it is not a substitute for review of the underlying evidence.
