# Publication Notice — WS-QX 0.1 Release Candidate

Worldshepherd publishes WS-QX 0.1 as an open repository release candidate for claims-controlled qualification evidence.

The central design rule is simple: a requirement is not evidence, and a claim may not be promoted beyond evidence actually observed.

The release candidate introduces a reusable qualification evidence envelope, independent physical/assurance/replication evidence axes, fail-closed claim promotion, and the first domain profile, WS-SEMCAP-01, for semantic edge communications. WS-SEMCAP explicitly separates transmitted-data reduction from retained mission utility so an attractive compression result cannot conceal loss of mission-critical information.

This publication is intentionally bounded. It does not claim physical validation, UAS flight validation, external replication, standards certification, partner validation, DARPA DV019 qualification, or Direct-to-Phase-II eligibility.

WS-QX is intended to let future Worldshepherd work accumulate reproducible evidence before opportunities appear, while keeping simulation, software implementation, physical testing, external validation, and independent replication visibly distinct.
