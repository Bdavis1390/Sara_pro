# WS-QX: evidence before claims

WS-QX is Worldshepherd's qualification-evidence layer. It turns a simple principle into software: requirements describe what must be proven; they are not proof themselves.

WS-QX records reproducible evidence, keeps physical performance separate from assurance and external replication, preserves negative results, and blocks higher claim states unless their evidence prerequisites exist.

The first profile, WS-SEMCAP-01, targets semantic edge communications. It measures bandwidth reduction and retained mission utility independently, so aggressive data reduction cannot conceal lost mission-critical information.

WS-QX 0.1 is a software release candidate. It does not claim physical validation, external validation, certification, UAS flight validation, DARPA qualification, or independent replication.
