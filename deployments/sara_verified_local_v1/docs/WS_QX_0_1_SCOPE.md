# WS-QX 0.1 Scope Freeze

Release-candidate scope is now frozen for exact-head CI.

In scope: common evidence envelope, fail-closed promotion, evidence axes, schema, semantic-edge metrics/profile, adversarial/negative tests, PRE delta template, partner exchange, DV019 crosswalk/decision packet, provenance reconciliation, claims/security/replication policies, release metadata.

Out of scope for 0.1: physical/HIL execution, production attestation, production PKI, CUI authorization, external blind test execution, independent replication, UAS flight test, standards certification, and program-specific eligibility determination.

Changes after this freeze require a new exact-head CI evaluation before protected-main publication.
