# WS-QX 0.1 — Release Notes

WS-QX is introduced as a claims-controlled qualification substrate for Worldshepherd.

Included in this release candidate:

- EVIDENCE-01 domain-neutral qualification envelope.
- Explicit physical/external claim-promotion interlocks.
- Independent physical-performance, assurance/TEVV, and replication/external evidence axes.
- WS-SEMCAP-01 semantic-edge qualification profile.
- Semantic communications metric evaluator separating transmitted-data reduction from retained mission utility.
- Tests proving high compression cannot hide failed utility and that internal qualification cannot silently become physical/external validation.
- Controlled WS-SEMCAP experiment manifest with all program/physical/external claims false by default.
- Reconciliation note preserving PR #266 as historical exact-head CI evidence without merging a branch that has diverged substantially from current main.

Claims boundary: IMPLEMENTED IN SOFTWARE / TESTS PROPOSED TO CI. No physical, external, standards, UAS-flight, DARPA-program, or partner qualification is claimed by this release candidate.
