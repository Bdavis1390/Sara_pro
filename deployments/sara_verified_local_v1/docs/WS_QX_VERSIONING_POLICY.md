# WS-QX Versioning Policy

Qualification profile versions are part of evidence identity.

Changing a metric definition, baseline, mandatory dimension, threshold interpretation, safety interlock, evidence requirement, or promotion rule requires a profile/version change or an explicitly recorded compatible revision. Historical evidence remains bound to the profile under which it was produced.

A newer profile must not retroactively relabel historical results as passing unless an explicit migration/re-evaluation record demonstrates that the original retained evidence is sufficient for the new rule set.

This prevents moving qualification criteria from silently rewriting history.
