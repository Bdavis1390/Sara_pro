# WS-QX Replication Ladder

Replication is tracked separately from internal assurance and physical performance.

R0 — no replication evidence.
R1 — repeated by same operator/environment.
R2 — repeated by different internal operator and fresh environment.
R3 — externally controlled blind test using supplied protocol/input package.
R4 — external reproduction with independently configured environment under declared equivalence criteria.
R5 — independent replication with independently sourced implementation/equipment where applicable.

The ladder does not imply that every domain can reach every level or that a higher level automatically validates every claim. Each replication record must identify the claim, configuration equivalence, protocol, deviations, and provenance.
