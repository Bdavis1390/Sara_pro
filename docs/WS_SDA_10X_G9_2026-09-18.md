## 1. Objective

G9 converts "10x more secure" from an aspiration into a falsifiable measurement
contract.

The evaluator forbids an aggregate score from hiding a failed critical dimension.

A 10x-security eligibility result requires:

1. every mandatory security metric to pass independently;
2. every mandatory utility non-regression metric to pass independently;
3. baseline and candidate measurements to use the same frozen G8 workload;
4. baseline and candidate measurements to use the same declared environment;
5. required sample counts and units to match the frozen protocol;
6. at least one genuinely non-zero baseline metric to demonstrate a measured
   candidate/baseline ratio <= 0.10.

If a baseline metric is already zero, it becomes a zero-invariant. It is not counted
as an infinite improvement.

## 2. Frozen workload binding

The protocol binds to the exact G8 V1 corpus content:

```text
WS-SDA-G8-ADVERSARIAL-CORPUS-V1
SHA-256:
324cc3d955c08b965f957667b7519e8c358af80c647acbd34611a13d8abe9a94
cases: 60
mandatory false-negative budget: 0
```

Changing the workload requires a new benchmark protocol/version.

## 3. Mandatory security dimensions

G9 V1 defines ten mandatory lower-is-better dimensions:

1. unauthorized observation acceptance rate;
2. replay-mutation acceptance rate;
3. transport-identity bypass rate;
4. release-authorization mutation escape rate;
5. release-replay acceptance rate;
6. DDIL conflict auto-resolution rate;
7. provenance-tamper miss rate;
8. adapter secret-exposure rate;
9. adapter network-egress success rate;
10. G8 adversarial false-negative rate.

For a non-zero baseline:

```text
candidate / baseline <= 0.10
```

is required.

For a zero baseline:

```text
candidate == 0
```

is required and recorded as a preserved zero-invariant rather than a 10x
improvement.

## 4. Utility cannot be sacrificed silently

Five mandatory utility gates run separately:

- task success rate;
- false-positive deny rate;
- p95 ingest latency;
- evidence completeness rate;
- replay determinism rate.

These are **not** averaged into the security score.

A candidate that improves security while violating any mandatory utility budget is
not eligible for the bounded 10x-security result.

This prevents a useless system that denies everything from being described as
"better."

## 5. Evaluator behavior

`worldshepherd_sara/sda_10x_benchmark.py` fails closed on:

- different baseline/candidate environments;
- different workloads;
- workload not matching the frozen G8 digest;
- missing metrics;
- unexpected metrics;
- duplicate metric IDs;
- unit mismatch;
- insufficient sample count;
- non-finite/negative measurements;
- security ratios above 0.10;
- regression from a baseline-zero security invariant;
- mandatory utility regression.

The report exposes every metric result and does not compute a compensating average.

The current branch is at **PROTOCOL_FROZEN / EVALUATOR_IMPLEMENTED**.

Unit tests use explicitly synthetic measurement bundles to test evaluator semantics.
Those fixtures are not real performance/security measurements and must never be
reported as a 10x result.

## 7. Required real-measurement procedure

Before an internal G9 PASS can be claimed:

1. freeze a comparable baseline implementation/commit for every metric;
2. provision the declared reference environment;
3. execute the exact G8 workload against the baseline;
4. record raw counts/timings and evidence references;
5. execute the same workload against the candidate;
6. validate sample counts, workload digest and environment identity;
7. run the G9 evaluator;
8. preserve raw evidence and the complete report;
9. investigate every failed mandatory dimension rather than averaging it away.

Metrics that lack a genuinely comparable baseline remain **NOT YET MEASURED**.

## 8. Claims boundary

Even an internal G9 PASS would mean only:

> On the frozen G9 protocol, G8 workload, environment, baseline and candidate
> evidence, every mandatory improvable security metric demonstrated at least a
> 10x reduction, baseline-zero security properties remained zero, and mandatory
> utility gates did not regress beyond their predeclared budgets.

It would **not** mean:

- universally 10x more secure;
- 10x against every attacker or mission;
- operational space-domain superiority;
- penetration-test completeness;
- classified-network approval;
- CMMC/NIST/FIPS/SLSA certification or conformity;
- government/customer acceptance;
- independent replication.

Those require separate evidence.
